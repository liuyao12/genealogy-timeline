# AI research prompt

The web app generates a version of this prompt containing the currently selected profile and tree root as stable anchors.

> Research the publicly documented family branch I describe. Prepare an import package for the Lineage genealogy-timeline web app.
>
> Repository: https://github.com/liuyao12/genealogy-timeline
>
> Schema: https://github.com/liuyao12/genealogy-timeline/blob/main/docs/import-schema.md
>
> Example: https://github.com/liuyao12/genealogy-timeline/blob/main/examples/stitch-import.example.json
>
> Read the schema and example before answering. Return exactly one JSON object using schema `lineage-stitch` and version `1`. Do not wrap it in Markdown and do not add commentary. Use public attributable sources only; preserve supplied anchor IDs exactly; include every referenced person; make relationships reciprocal; distinguish formal spouses from non-marital partners; and include source attribution for every researched profile. Consult Wikipedia, Wikidata, official biographies, and other reliable public sources to build an evidence-based chronological `namePeriods` list for each person, including changes of name, style, or title.

Use **Prepare research prompt** in the app to obtain the complete prompt with the current tree's anchors and the detailed validation rules.
